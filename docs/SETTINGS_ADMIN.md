# 设置中心与管理页面

## 页面

常规设置、外观设置、模型管理、知识库设置、Agent 设置、存储与数据、关于。

### 常规

启动行为、默认工作区、语言、通知、危险操作确认、隐私/诊断偏好。

### 外观

浅色/深色/跟随系统、语言、字体大小、界面密度、动画开关、是否显示 Agent
Workspace。主题必须即时生效并持久化。

### 模型管理

Provider、模型、端点、密钥状态、连接测试、默认聊天/规划/Embedding
模型、temperature、max_tokens、超时。

### 知识库设置

默认知识库、Embedding 模型、Chunk Size/Overlap、Top
K、相似度阈值、reranker、引用展示、处理并发。

### Agent 设置

默认
Agent、自动选择、最大步骤/工具次数、超时、重试、自动检索、自动调用工具、高风险确认、流式输出、Workspace
显示。

### 存储与数据

数据库连接、文件目录、知识库目录、缓存/日志/临时文件、占用、备份/恢复/清理。危险操作必须展示影响并确认。

### 关于

产品名、版本、构建信息、许可证、依赖说明。更新检查只有接入真实更新源后才启用。

## 持久化

设置需定义类型、默认值、校验、敏感级别、应用时机和迁移策略。密钥不能由普通
settings API 返回。

## 验收

重启后设置保留；模型默认值影响新任务；知识库参数影响真实入库/检索；主题即时生效；密钥不进入日志或响应。
