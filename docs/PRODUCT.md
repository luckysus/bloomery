# Suna 产品定义

## 定位

Suna 是面向钢铁材料研发的桌面端 AI Agent
工作平台，不是普通聊天机器人或静态管理后台。用户通过自然语言发起科研任务，平台在可控权限下规划步骤、调用知识/文献/数据/预测/优化能力，并返回可追溯结果。

## 科研闭环

用户问题 → 任务识别 → 计划 → 知识/文献检索 → 数据分析 → 性能预测 →
工艺优化 → 实验设计 → 报告 → 保存与复现。

## 模块

新对话/对话中心、知识中心、文献研究、数据实验室、性能预测、工艺优化、实验助手、Agent
管理、工具中心、MCP 管理、Skill
管理、模型管理、设置中心、任务历史与诊断。

## Agent

-   Master Agent：理解目标、协调步骤、汇总结果。
-   Knowledge Agent：知识库检索和引用。
-   Literature Agent：文献检索、解析、摘要、比较。
-   Data Agent：数据清洗、统计和可视化。
-   Prediction Agent：调用已配置的材料性能预测服务。
-   Optimization Agent：在明确约束下运行算法。
-   Experiment Agent：生成可审核的实验设计建议。
-   Report Agent：整理结果、证据、图表和限制。

Agent 必须定义输入输出
schema、工具权限、模型配置、超时、最大步数和失败策略。

## 屈服强度特殊路由

只有用户意图明确为"预测屈服强度"且至少提供一个成分或工艺参数时，才进入屈服强度预测服务。抗拉强度、延伸率等未支持指标必须明确告知未支持，不得误调用屈服强度服务。缺少必需参数时追问；服务失败时报告失败，绝不编造结果。不得把内部意图
JSON、密钥或隐藏提示词展示给用户。

## 产品原则

1.  真实状态，不用随机数或延时伪造 Agent 运行。
2.  重要结论关联真实文献、数据、模型版本或工具记录。
3.  工具采用最小权限；危险/昂贵操作需确认。
4.  支持取消、有限重试、错误恢复和任务历史。
5.  Mock 只能用于开发测试，必须明确标记。
6.  预测和优化结果应说明适用范围、数据来源与验证限制。
