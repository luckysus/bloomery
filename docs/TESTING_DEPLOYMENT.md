# 测试、可靠性、部署与发布

## 测试层

单元测试：状态机、参数校验、权限、单位转换。集成测试：数据库、模型
Provider、Tool Runtime、文件入库、向量检索、Python API。端到端：启动 →
创建会话 → 发任务 → 收事件 → 得回答 → 重启后读取历史。UI
测试覆盖导航、表单、主题、错误状态和取消按钮。

## Mock

Fake LLM/Tool
只用于测试；正式模式不得静默回退。报告必须注明测试使用真实服务还是
Fake。

## 日志

结构化日志包含
request_id/task_id/agent_run_id/tool_call_id；过滤密钥、密码和不必要的完整文档内容。诊断导出前脱敏。

## 可靠性

备份数据库与文件；恢复前检查版本；上传失败可重试；临时文件可清理；迁移失败不得静默运行在未知状态。

## 打包

Tauri 2 安装包；明确 Python sidecar 或独立服务的交付、启动、端口/IPC
和退出清理方式。干净环境不能依赖开发者本机工具链。

## 安全

检查凭证、上传限制、路径穿越、SQL 注入、外部
URL、工具权限、本地端口、日志脱敏、依赖许可证和更新签名（若实现）。

## 发布验收

干净环境按文档安装；至少一个真实模型、一个工具和一个知识检索流程可工作；升级/卸载不意外删除用户数据；备份可恢复。
