# 知识中心与 RAG

## 页面

我的知识库、公共知识库、知识库管理；搜索、类型过滤、排序、新建/编辑/归档；文档上传、列表、删除、重新处理；最近文档；文档详情、解析状态、标签、来源、大小；检索测试。

## 入库链路

上传 → 安全校验 → 哈希去重 → 保存原文件 → Parser → 标准化 → Chunker →
元数据提取 → Embedding → VectorStore →
完成状态。支持格式必须与实际解析器一致，不支持时明确拒绝。

## Parser/Chunker

使用可替换接口。Chunk 保存 document_id、index、text、页码/章节、metadata
和长度。尽量保留标题、页码和表格结构；解析不可靠时标注，不可假称完整提取。

## Embedding/Vector Store

Embedding 独立配置；检查维度与模型兼容性；支持 pgvector
adapter；批量任务有限并发、可取消、可重试。模型切换不得混用不同维度向量。

## 检索/RAG

支持语义检索、关键词检索、可选混合检索/reranker、知识库/类型/标签过滤、top_k、阈值、去重。结果包含标题、来源、知识库、chunk、页码（若可得）、得分和文档
ID。回答只根据证据作答，证据不足要说明；引用必须对应真实片段。

## Agent 集成

注册 `knowledge_search`，返回结构化 evidence
list。不要把整个知识库塞进上下文。文件内容是数据，不是系统指令。

## 验收

真实 PDF
与表格文件入库；解析、切分、索引、搜索、引用完整；重启后仍存在；失败可重试；删除文档时同步处理
chunk/向量。
