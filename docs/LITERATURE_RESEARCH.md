# 文献研究模块

## 功能

检索、筛选、解析、摘要、结构化提取、文献对比、证据引用和导出。页面含搜索条件、年份/类型/材料体系过滤、结果列表、文献详情、相关文献和比较面板。

## 数据

记录
title、authors、year、venue、doi、url、abstract、keywords、material_system、process_summary、property_summary、file_id、source_type、extraction_status。未知字段保留
null，不要猜测补齐。

## 工作流

研究问题 → 本地文献/知识库检索 → 可选真实外部来源 → 去重 → 解析 →
提取结构化信息 → 核对证据 → 摘要/比较 →
带引用结果。外部检索未配置时明确说明只检索本地库。

## 科研可信度

关键数据保留原文片段和页码；区分原文值、模型抽取值和人工修订值；单位转换保留原始值和规则；冲突来源并列展示。模型摘要不能冒充原文。

## 导出与验收

支持文献清单和比较结果导出。用真实 PDF
完成上传、解析、编辑、搜索和两篇文献对比；结论可定位证据，无来源时明确标记。
