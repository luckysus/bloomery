# 数据实验室

## 功能

CSV/XLSX
导入、预览、字段映射、缺失/重复/异常检查、清洗、描述统计、相关性、分布、分组比较、图表、数据集版本和导出。

## 数据规则

保留原文件；清洗默认生成新版本，不覆盖原始数据。每步记录行数变化、操作规则和错误行。区分数值、类别、文本、日期和单位；缺失值不得随意转成
0。超大文件采用分块处理。

## 分析引擎

可使用 Python
pandas/scikit-learn。长任务异步运行并提供真实进度。统计结果注明样本数、缺失处理方式和算法参数。

## Agent 工具

data_profile、data_query（受限只读）、data_analyze。输入输出 schema
明确；禁止 Agent 任意修改生产数据库。

## 验收

真实导入
CSV/XLSX，展示列类型、缺失统计和至少三种图表；清洗后生成新版本；导出文件可重新读取；错误文件有明确反馈。
