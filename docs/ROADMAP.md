# Suna 开发路线图

## M0 仓库审计

盘点代码、UI、依赖、数据库、服务与测试；输出
`docs/IMPLEMENTATION_STATUS.md`。不大规模写代码。

## M1 工程与 UI Shell

启动桌面框架、路由、Design
Token、Sidebar、Header、三栏布局和空/加载/错误状态。验收：应用可启动，页面可导航。

## M2 持久化与 API

实现迁移、会话、消息、任务、事件、配置和健康检查。验收：重启后历史仍存在。

## M3 模型 Runtime

实现 Provider
抽象、密钥安全、连接测试、流式输出；至少接入一个真实模型。验收：真实模型可回答，失败可诊断。

## M4 Agent Runtime

实现状态机、Planner、Executor、Dispatcher、事件、取消、超时、有限重试。验收：真实任务闭环可追踪。

## M5 Tools/MCP/Skills

先做只读工具和权限，再做一种 MCP 传输方式与 Skill
版本管理。验收：授权、执行、失败、审批和审计可测。

## M6 知识中心/RAG

上传、解析、切分、Embedding、pgvector、检索、引用、重试。验收：真实文件可检索并显示来源。

## M7 文献与数据实验室

分别实现文献导入/解析/检索与数据导入/清洗/分析/导出。

## M8 性能预测

接入真实屈服强度服务，遵守指标路由和参数校验。

## M9 工艺优化与实验助手

先用可复现测试函数验证算法，再连接真实材料预测器。

## M10 设置、报告、打包

完成持久化设置、诊断、备份恢复和干净环境安装验收。

每个阶段结束都要报告通过测试、Mock、外部配置、未完成项和下一阶段前置条件。不能仅凭代码写完跨阶段。
