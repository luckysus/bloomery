# 性能预测模块

## 目标

实现材料性能预测工作流，优先接入已有钢材屈服强度预测服务。未配置真实服务时不能编造数值。

## 输入

按真实 schema 定义成分与工艺字段、类型、单位、必需性和校验范围。不得混用
wt.%、质量分数、温度等单位。保存原始输入、转换规则和实际请求体。

## 路由

仅当意图为屈服强度预测且用户提供至少一个成分或工艺参数时，调用屈服强度服务。抗拉强度、延伸率等未支持目标必须告知未支持，不得返回屈服强度冒充。必需参数缺失时追问。一般材料问答走正常问答/RAG。禁止泄露内部意图
JSON。

## 记录与 UI

保存
run_id、时间、服务/模型版本、输入、单位、状态、输出、错误和适用范围。UI
有指标选择、参数表单、校验、运行状态、结果卡、历史记录和导出。

## 失败处理

服务超时/不可用时显示真实错误，保留输入并允许重试。日志脱敏。只有真实接入多个模型并明确评估数据时才展示模型对比。

## 验收

合法请求调用真实服务；非法输入本地拦截；不支持指标不误调用；服务不可用不伪造结果；历史可查看。
