# 主界面、对话中心与 Agent Workspace

## 布局

按用户参考图实现左侧导航、中间工作区、右侧 Agent Workspace
的桌面三栏。主界面含欢迎
Banner、核心模块卡片、研究灵感、输入框、附件/知识库/Web
搜索/工具入口、模型选择和发送按钮。

## 会话

创建、重命名、归档/删除、最近会话、消息历史和附件关联。消息持久化。切换会话时必须隔离旧任务事件。

## 消息

支持
Markdown、代码、表格、引用和工具调用摘要。隐藏推理链不可展示。流式响应中断时显示恢复状态，不允许永远转圈。

## Workspace

展示当前任务、Master/子 Agent
状态、真实进度、步骤时间线、工具名/耗时/摘要、取消/暂停/继续。所有状态来自真实
TaskEvent；无任务时显示空状态，不能硬编码 68% 等进度。

## 发送链路

提交 → 保存用户消息 → 创建任务 → 订阅事件 → 展示流式文本/事件 →
保存最终结果。失败时保留输入并可重试。停止按钮必须真正取消后端任务。

## 验收

创建多个会话、真实模型流式回答、查看事件、停止任务、重启后读取历史。无密钥时提示配置，不伪造回答。
