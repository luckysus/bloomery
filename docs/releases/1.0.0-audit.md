# Bloomery 1.0.0 Release Audit

审计日期：2026-08-13
审计基线：`main` 分支当前提交  
审计结论：**尚不能声明正式 1.0.0 发布**

这份文档按发布设计和质量计划逐项记录当前证据。工程测试通过不等于正式发布完成；没有当前、直接、可复现证据的项目保持未完成状态。

## 结论摘要

| 状态 | 含义 |
| --- | --- |
| 已证明 | 当前源码、测试、脚本或产物直接提供了证据 |
| 部分证明 | 主要实现存在，但完整发布范围仍缺少一项或多项证据 |
| 未证明 | 没有足够的当前证据，不能打勾 |
| 发布阻断 | 在正式公开发布前必须解决 |

当前判断：

- Gate A（独立本地外壳）：**已证明**
- Gate B（本地持久化平台）：**已证明**
- Gate C（证据型本地 RAG）：**已证明**
- Gate D（模块化智能体运行时）：**已证明**
- Gate E（受控扩展生态）：**已证明**
- Gate F（完整钢铁工作台）：**部分证明**
- Gate G（桌面产品体验）：**部分证明**
- Gate H（公开正式发布）：**未完成 / 发布阻断**

### 本轮修复证据（2026-08-13）

- MCP 配置与凭据更新现在以同一条应用级补偿流程提交；数据库保存失败、凭据部分写入失败和凭据删除失败都会恢复此前凭据快照。
- MCP 编辑时会同时清理旧环境变量名称对应的凭据，避免重命名后遗留系统凭据。
- 多个不同领域包可以同时激活；聊天提示词、内置工具白名单和本地检索证据上限会按所有活动领域包计算。
- 旧的单领域提示词包装函数已删除，生产调用统一使用复数领域 API。
- 本轮验证：Rust 全量 `110` 个主库测试及所有集成目标通过；MCP 回滚测试 `2/2`、领域包测试 `20/20`、领域工具测试 `3/3`、桌面提示词测试 `13/13`；前端测试 `93/93`；Rust 格式、发布脚本契约、前端边界和安全门禁通过。
- 当前版本统一后的完整 `scripts/release-check.ps1 -Package -InstallerSmoke -AllowDirty -Offline` 已通过：前端 `93/93`、Rust 主测试 `110/110`、Worker `74/74`、钢铁评测 `4/4`、发布契约、安全检查、迁移和备份生命周期检查均通过；同时生成了当前 `1.0.0` NSIS/MSI 候选包。
- Windows 10 跨版本矩阵已使用历史 `0.1.0` 和当前 `1.0.0` 未签名工程包完成 `old-install → upgrade → downgrade`，并通过全新安装 smoke、启动、卸载、Unicode 安装路径、非默认数据目录和数据保留检查；报告为 `artifacts/windows10-lifecycle-1.0.0.json`。
- 生命周期脚本已改为使用 Unicode code point 构造中文目录名，并增加契约测试，避免 Windows PowerShell 5.1 将无 BOM UTF-8 中文字面量误读为乱码。Windows 11 已明确延期，不阻断当前 Windows 10 发布。

## 不应做的发布声明

在上述阻断项关闭前，不应使用以下表述：

- “Bloomery 1.0.0 正式版已发布”；
- “Windows 10 已完成全部发布验收”；
- “安装包已签名”；
- “更新器已完成正式验证”；
- “完全离线”；
- “所有钢铁工业指标都已通过真实生产数据验证”。

当前正确表述是：**Bloomery main 分支已具备面向 Windows 10 的 1.0.0 未签名工程候选包；核心本地智能体、发布检查和 Windows 10 工程包生命周期矩阵已通过，但正式签名、干净环境审计、Updater 正式验证和最终公开发布仍未完成。Windows 11 兼容性验证延期。**

## 下一步验收顺序

1. 配置受保护的正式签名环境，生成并验证安装包、计算 Worker、官方领域包和 updater 清单签名。
2. 从 clean checkout 和 fresh Windows profile 运行完整 `release-check.ps1`，补齐 Unicode 用户名和首次对话体验记录。
3. 完成公开钢铁案例研究，再逐项更新本审计和路线图复选框。
4. 创建正式 `v1.0.0` tag、GitHub Release，并同步 Gitee 发布说明和校验文件。
5. 后续具备 Windows 11 环境后，重复安装、升级、卸载、数据保留和性能矩阵。

每一项关闭都必须附带命令、提交 SHA、产物路径或手工环境记录；仅凭“代码已实现”不能关闭发布 Gate。
