# 产品边界

简体中文 · [English](NON-GOALS.en.md)

Bloomery 是本地优先的领域智能体工作台。本页说明产品有意不提供的内容，帮助用户和贡献者理解项目边界。

## 1. 不要求 Bloomery 账号或项目专属云服务

本地工作区可以在不登录 Bloomery 的情况下使用。模型、Embedding、Reranker、文档解析和其他外部服务由用户自行配置；项目不要求用户接入由维护者运营的专属后端。

## 2. 不分发受限制的标准原文

钢铁和材料标准可以按标识符或来源进行引用，但项目不复制或分发受版权、许可或访问限制约束的标准原文。用户导入和使用资料时，应自行确认相应的使用权限。

## 3. 不在未经确认时执行高风险操作

写入文件、执行 Shell 命令和其他高风险工具操作不会在用户不知情的情况下静默执行。扩展能力也必须遵循工具注册和权限确认规则。

## 4. 不默认上传用户的本地数据

会话、知识库、记忆、任务和配置默认保存在本机。只有用户主动配置并启用的模型、检索、解析、MCP 或更新服务，才可能产生网络请求。

## 5. 不绑定同一项目中的 Web 应用

桌面客户端作为独立的本地应用运行，不依赖同一项目中的 Web 前端、私有后端 API 或 Web 登录状态。
