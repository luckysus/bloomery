# 工艺优化与实验助手

## 工艺优化

输入材料体系、可调变量、上下界、固定参数、目标函数、约束、评价器、算法、停止条件和随机种子。每个变量都要有单位与范围来源；未知范围需用户确认。

通过适配接口接入 NSGA-II、Bayesian Optimization
等算法。记录算法版本、参数、随机种子、目标值、约束违反、耗时和状态。结果显示
Pareto
图（适用时）、候选方案、预测指标、约束状态、基线对比和可复现配置。

优化结果是给定模型/数据下的候选方案，不得宣称为真实生产最优工艺；应提示实验或工艺验证。

## 实验助手

支持目标、因素与水平、样本/资源约束、设计矩阵、随机化信息、方案版本、实验结果导入和实际/预测对比。只展示已实现算法。

## Agent 集成

缺少可靠预测器或约束时不可凭空优化。真实生产/实验执行必须由用户审核。

## 验收

先用可复现测试函数跑通优化，再接真实预测器；运行配置与结果可保存、重载，违反约束的方案明确标记。
